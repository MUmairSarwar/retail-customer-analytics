# Data

The analysis uses the UCI **Online Retail** dataset (DOI: 10.24432/C5BW33).
It contains transactions from a UK-based online retailer between December 2010
and December 2011.

The raw Excel file is not stored in this repository. Running the pipeline
downloads it from UCI and saves it under `data/raw/`.

Generated summary tables are stored in `data/processed/`. They are included so
the dashboard can be reviewed without downloading the full source file.
